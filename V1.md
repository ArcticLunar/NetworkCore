# NetworkCore V1

这份文档定义 `NetworkCore V1` 的交付边界。

## V1 已完成

### 核心请求链路

- `APIEndpoint` / `NetworkClientProtocol` / `NetworkClient`
- `RequestBuilder`
- `AlamofireTransport`
- JSON / form / multipart / upload / download / background download
- `request(...)` 和 `requestData(...)`
- 下载响应延迟读取 `loadData()`

### 默认生产策略

- `NetworkDefaults.makeProductionConfiguration(...)`
- `NetworkDefaults.makeProductionClient(...)`
- 默认重试策略 `DefaultRetryPolicy`
- 默认响应校验：
  - `HTTPStatusCodeValidator`
  - `EmptyDataValidator`
  - `ContentTypeValidator`
- 默认缓存存储 `URLCacheNetworkCacheStore`
- 默认 observability profile
- 基于 `baseURL` 的默认安全策略

### Auth

- `AuthCredentialsStore`
- `TokenRefresher`
- `AuthRefreshCoordinator`
- proactive refresh
- refresh 并发去重
- unauthorized retry 重走 request adaptation
- refresh failure policy

### Observability

- request start / retry / finish
- structured logger
- metrics sink
- redaction
- debug / staging / release profile
- endpoint 级 header/body logging override
- decode degraded observability
- stream observability
- circuit breaker transition observability
- background transfer logger / metrics observer

### Safe decoding

- `NetworkDecodingPolicy`
- `SafeJSONResponseDecoder`
- 全局 `defaultDecodingPolicy`
- endpoint / streaming endpoint 级 override
- safe wrappers：
  - `Defaulted`
  - `LossyArray`
  - `LossyDictionary`
  - `StringBackedInt`
  - `StringBackedBool`
- 默认仍为 `.strict`
- `.safe` 需要 endpoint opt-in 和 DTO wrappers 同时到位

### Cache

- `NetworkCachePolicy`
- `NetworkCacheStore`
- TTL
- cache key normalization
- `ETag` / `Last-Modified` 条件请求
- `304 Not Modified` 重验证回落
- `staleWhileRevalidate`

### Reachability / resilience

- `NetworkReachabilityMonitor`
- endpoint 级 `reachabilityRequirement`
- unsatisfied path behavior
- expensive / constrained upload limits
- `CircuitBreaker`
- `EndpointFailureTracker`
- stream reconnect gating 与 circuit breaker 联动

### Streaming

- SSE
- WebSocket
- `openStream(...)`
- `NetworkStreamConnection`
- WebSocket `send` / `ping` / `close`
- SSE reconnect / `Last-Event-ID`
- reconnect backoff / jitter / budget
- reachability gating
- app lifecycle gating

### Background transfer

- `BackgroundDownloadManager`
- pause / resume / restore
- persisted records
- active task rebind
- system completion handler coordination
- structured failure reason

## V1 明确不纳入

- 更多 streaming 协议类型
- 更复杂的多级缓存产品化策略
- 高级 metrics cardinality 治理平台能力
- 面向外部发布的 binary distribution 体系

## V1 接入要求

- 优先使用 `NetworkDefaults` production preset
- 应用特有实现通过协议注入
- endpoint 级差异放到 `RequestOptions`
- 业务层不要自行 new `Session` 或手拼 transport
- 背景下载 session identifier 统一来源于 `NetworkDefaults.defaultBackgroundDownloadSessionIdentifier(...)`

## 当前结论

`NetworkCore` 当前已经具备 `V1 production-ready` 的框架能力边界，可以作为独立框架集成到应用工程中。
